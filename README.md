# AWD-脚本
作者写的使用教程和介绍

https://mp.weixin.qq.com/s/OQzkSdt69dqQgIdkAYmfLw

本篇是为入门网络安全学生撰写。以一名网络安全学生的视角，在大学间学习了很多网络安全知识，根据竞赛整体情况我个人将其分类为CTF、AWD、SRC、HVV四个大学习方向。四者间有相同之处，但在比赛模式上大有不同。其中AWD在四者中接触最少，大多数为模拟实战实时进行多方互相攻击与自身防御巩固。

对于新手来说，搜集关键词"AWD"得到的会是眼花缭乱的文章，其中因为AWD的实际赛制还有多种细分，有时难以实际利用。对于最开始的我也是其中一员，拿到长篇的内容却不知道如何下手。所以本次，手搓了两百行懒人专用脚本。同时，我的内容只写最普遍AWD赛制(比赛开始就直接开放攻击)攻击和防御通用的，避免大家看的厌烦，希望可以帮助到有需要的你。
